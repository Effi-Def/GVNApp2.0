Place your custom avatar images here.

How to use:
- Add PNG/JPG files to this folder (e.g., p1.png, team.png)
- In Settings > Profile, type: avatars/p1.png and click "Usa immagine"
- Or paste a full URL (https://...) which will be stored as url:...

Tech notes:
- Files under public/ are served at the site root, so avatars/p1.png is accessible at /avatars/p1.png
- The avatarKey supports:
  - pig-N (default emoji avatars)
  - img:avatars/<file>
  - url:https://<address>
